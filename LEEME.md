# PDF a EPUB

Abrí **Abrir herramienta.cmd**, elegí o arrastrá los PDF y pulsá **Convertir a EPUB**. Los resultados están en la carpeta **epub**, que también podés abrir desde la aplicación. Un archivo con el mismo nombre reemplaza al EPUB anterior después de comprobar el nuevo.

Los idiomas se comparan automáticamente, incluso por renglón en una misma página. Se utilizan los idiomas de reconocimiento instalados en Windows, que aparecen en la interfaz. El OCR es el integrado en Windows y requiere que el idioma elegido tenga instalada la función de reconocimiento de texto de Windows. No se usan modelos de lenguaje ni servicios externos. La capa de texto existente se aprovecha cuando está disponible.

Al terminar, **Revisar** muestra posibles confusiones entre números y letras, el contexto y una imagen del original. Podés usar **Corregir todo** para aplicar el lote completo con un clic, o revisar y editar sugerencias individuales. El texto no se cambia automáticamente. La revisión y las imágenes del PDF original están disponibles mientras la aplicación siga abierta; el EPUB guardado permanece en la carpeta de salida.

Las sugerencias utilizan diccionarios incluidos de español e inglés y vocabulario adicional en `internos/diccionarios/vocabulario.txt`, que se puede ampliar. Buscan confusiones entre cifras y letras, incluidas varias cifras por palabra y acentos, y ciertas confusiones tipográficas cuando otra forma aparece repetidamente en el libro; no detectan todos los errores ortográficos ni todos los errores de contexto. Si el PDF conserva información de cursiva, no se ofrecen sugerencias en las palabras en cursiva; el resto del renglón se revisa aunque tenga fragmentos con formato; en páginas escaneadas el OCR de Windows no identifica de forma fiable la cursiva.

Durante la conversión se informa si el libro necesita OCR (reconocimiento óptico de caracteres) y cuántas páginas lo requieren. Se eliminan folios en los márgenes y encabezados repetidos, aunque cambien ligeramente de posición. Las notas identificadas se guardan en una sección EPUB de notas, con enlaces desde las referencias reconocidas y enlaces de regreso. Los índices impresos detectados se reconstruyen como navegación, sin copiar los líderes de puntos. Se reconocen entradas repartidas entre varios renglones y se agregan las secciones identificadas por su tipografía, separación y numeración. Si no hay un índice utilizable, se genera a partir de esos títulos. Los enlaces de las secciones apuntan al título correspondiente. Estas reglas se calculan a partir de cada documento, sin perfiles por libro. Las tablas detectadas se conservan como imágenes del original, incluidas las que se identifican por cuadrículas o alineación de columnas en páginas escaneadas; no se reconstruyen como tablas de texto. Las ecuaciones y las ilustraciones identificadas también se insertan como imágenes; la detección en páginas escaneadas es conservadora y puede omitir figuras o fórmulas, especialmente si no tienen una leyenda reconocible. Revisá el EPUB, en particular si contiene muchas fórmulas, tablas o figuras. La comprobación de integridad verifica el archivo generado, no la exactitud del reconocimiento ni que se hayan detectado todos los elementos del original.

Instalación, si faltan dependencias: instalá Python, creá un entorno con `python -m venv .venv` y ejecutá `.venv\Scripts\python.exe -m pip install -r internos\requirements.txt`. El reconocimiento integrado requiere Windows. Los archivos de licencia de los diccionarios están en `internos/diccionarios`.

Las letras capitulares se integran al párrafo, y los títulos centrados en varios renglones se tratan como un único título. Las expresiones matemáticas aplanadas por una capa OCR previa se conservan como imagen cuando su estructura no es fiable. En unos pocos fragmentos sospechosos se vuelve a leer el recorte original para respaldar una sugerencia, sin repetir el reconocimiento de todo el libro.
